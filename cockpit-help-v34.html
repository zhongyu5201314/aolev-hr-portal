管理驾驶舱（日周月报）可视化升级说明

版本 v3 → v3.4　|　HR 门户「日周月报」→「驾驶舱」页签　|　更新时间 2026-10-27
内部资料 · 请勿外传

一、背景

驾驶舱此前为纯卡片 / 圆点 / CSS 条形，无图表。本期升级为 ECharts 真图表驾驶舱：一屏总览日报质量 / 周报进度 / 月报达成 / 闭环预警，并补齐红绿灯语义、历史月份切换、对标线与"仅看本部"等交互。

二、版本变更清单

版本主要变更
v3接入 ECharts（折线/柱状）。4 张主图：月度趋势折线、部门健康度柱状、个人 TOP 柱状、沉默字段双系列柱状。
v3.1趋势线末端加环比 ▲▼ 箭头；沉默字段由 2 张拆为 6 张小图表（按字段部门排行）。
v3.2部门柱状按四指标最差项红绿灯分色（绿=全达标黄=关注红=预警）+ 悬停看四指标明细；个人 TOP 补末位 3 人（红色"需关注"）。
v3.3顶部加全局健康度仪表盘（gauge）；预警"熔断条"改成熔断指标 vs 阈值柱状图（红=已触发）。
v3.4仪表盘历史月份一键切换（指针平滑过渡）；部门红绿灯矩阵→雷达图（区域按红绿灯着色 + 灰色虚线达标基准线 + 金色虚线全公司均值 + 青色点线公司目标线 + 「仅看本部对比」按钮）；部门柱状图加「仅看本部」+ 历史月份联动。

图表总数：12 张（仪表盘 + 趋势 + 雷达 + 部门柱状 + 个人TOP + 预警熔断 + 6 张沉默字段小图）。

三、交互速览（给使用者）

顶部仪表盘
点月份按钮切换历史月，指针平滑过渡；数值 = 该月四指标公司均值。
部门健康度雷达图
区域填充色 = 该部门红绿灯状态（绿黄红）；三条参考线：灰虚线=达标基准线（落在线内=未达标）、金虚线=全公司均值、青点线=公司目标线（占位待校准）；点图例可显隐任意系列；点「仅看本部对比」只看人事行政部 vs 全公司 vs 目标。
部门健康度柱状图
月份按钮（与仪表盘同源历史月）+「仅看本部」按钮可叠加（如"切到 8 月 + 仅看本部"）。
个人 TOP / 预警熔断 / 沉默字段
交互同前，悬停看明细；个人 TOP 红标 = 末位 3 人需关注。

四、数据口径与说明

  • 所有图表与四个明细页签共用同源数据（飞书日报 / 周报 / 月报 + OGSM 目标），仅做前端聚合，不拉飞书。
  • 红绿灯阈值 v2（达标导向）写在 cockpit.js 顶部 TH，可按管理偏好调整：出勤≥85 / 关联≥50 / 完整≥60 / 按时≥90 / 已对齐≥70 为绿，黄为关注，红为预警。
  • "日报填报率"为日报填报口径（截至数据日应出勤天数的填报覆盖），非 HR 真实出勤。
  • 周报承诺核销墙已改由门户 data/weekly_promises.csv 维护、可手工刷新（编辑 CSV → node bake_promises.js → 部署）。
  • 个人绩效分与 ⚠️ 低可信评价按门户脱敏策略不在公网展开，仅本地可见。
内部待办：① 公司目标线为占位参考值（RADAR_TARGET = {出勤95/关联65/完整75/按时95}），图内已标"占位待校准、非实测"，待 HR 提供四个指标真实目标值后替换（置 null 则该线不显示）。② GitHub PAT 轮换（部署用 token 多次出现，建议尽快在 GitHub 设置中轮换/撤销）。③ 雷达图固定展示统计月，仅部门柱状图支持历史月切换（设计取舍，保持与 KPI 一致）。
